description: Open ideas from earlier sessions in this project, or pick one up
argument-hint: "[words from an idea to pick up]"
---

If `$ARGUMENTS` is empty: call the kifu_ideas tool for this project and show the open ideas as a short list —
title, status, how long it has been quiet, and the first open loose end — then ask which one to pick up.

If `$ARGUMENTS` names an idea: call kifu_brief with it, summarize the brief in a few lines, look at the current
state of the files it mentions, and propose how to continue. Do not change anything before the user agrees.
